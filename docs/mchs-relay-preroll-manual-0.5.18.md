# Windows Radio Agent 0.5.18 — ручная проверка реле и подготовка усилителя

Исправления касаются **изолированного аппаратного испытания** с
физически отключённой от усилителя аудиолинией PA. Они не предоставляют
разрешения на автоматическое включение громкоговорителей при настоящем
Android-уведомлении.

## Ручная проверка GPIO13

В разделе «Эфир» появились кнопки:
- **Проверить реле: ON до 8 секунд** — ограниченный ручной запрос;
- **Реле OFF** — отмена запроса (периодическая отправка OFF/lease watchdog).

Они работают только при запущенном изолированном Agent, отдельно подтверждённом
режиме аппаратного испытания, выбранных локальных WAV и допуске GPIO13.
Кнопка ON не обходит платформу: `/agent/amplifier-intent` должен вернуть
`permit:true`. Чтобы проверить запрос, ответственный администратор
в существующем «Усилитель · ESP32» выставляет «Вручную» и «Запрос: ВКЛ».
Если сервер запрещает питание — реального ON не будет, GUI показывает причину.
По окончании ручного теста администратор возвращает штатный режим AUTO.

Важное отличие: галочка «Разрешить физическое управление реле» — допуск,
а не кнопка физического ON. Ручной запрос здесь короткий (до 8 секунд), а
не постоянный режим питания.

## 3 секунды подготовки усилителя

Только для **синтетического** учебного ALARM или отбоя:
1. Agent получает валидный START, прошедший существующую локальную проверку.
2. Agent останавливает свои центральные VLC-деки, чтобы не было музыки на
   выходе во время подготовки.
3. Agent публикует локальный идентификатор подготовки; GUI запрашивает
   штатный серверный `permit:true` и посылает HMAC-подписанный ON через ESP32.
4. Отсчёт **3.0 секунды** начинается только после успешного ответа ESP32
   на ON. Lease обновляется периодически; при старом подтверждении ждать.
5. По окончании выдержки, если есть свежее подтверждение ON и локальная
   авторизация не потеряна, запускается WAV. Иначе — отказ с причиной
   `RELAY_PREROLL_*`, **без запуска WAV**.
6. После завершения WAV отправляется OFF штатным 3-секундным циклом и
   центральный эфир возвращается, результат записывается в историю Agent.
   При остановке Agent аппаратный watchdog ESP32 выключает реле даже при
   потере сети.

## Границы и физическая проверка

Ответ ESP32 `ON_COMMANDED` не измеряет фактическое напряжение или готовность
усилителя AA-300. Периодический запрос OFF не заменяет аварийного аппаратного
размыкателя. До проверки с громкоговорителями следует измерить реальное
время готовности усилителя, зафиксировать отсутствие первого обрезанного
слога и протестировать связь/аварийное отключение.

На настоящие Android-уведомления это **не распространяется**: они пока
сохраняют изолированный путь в наушниках без автоматического GPIO13 ON.
Реальный PA потребуется выпускать отдельно после проверки pre-roll и
аппаратных межблокировок.
