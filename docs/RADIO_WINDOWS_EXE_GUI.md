# MEDIA · РАФ · RAW — Windows Radio Agent (.exe), этап 1

Цель: запускаемое окно Windows без необходимости устанавливать Python. Исходники: `radio-agent/windows/gui.py`. GitHub Actions компилирует `MediaRafRaw-RadioAgent.exe` на Windows x64 и публикует в *Actions → Windows Radio Agent EXE → последний успешный run → Artifacts*.

## Установка на тестовый компьютер

1. Скачайте артефакт `MediaRafRaw-RadioAgent-Windows-x64` и извлеките `.exe` из ZIP. Это настоящий Windows executable, **не веб-страница**. Артефакт появляется только после успешного Windows build.
2. Установите **VLC для Windows**, если он ещё не установлен. Аудио выводится через устройство, назначенное Windows/VLC; сборка пока не включает сам VLC.
3. На сайте администратор добавляет отдельный радиокомпьютер, копирует его `rr_...` токен и **разрешает PILOT**. Токен нельзя публиковать или передавать в чате.
4. Дважды щёлкните `MediaRafRaw-RadioAgent.exe`; в окне укажите HTTPS сервер, токен, `vlc.exe` и папку кеша.
5. **Физически отключите школьную акустику и усилитель**, подключите наушники, отметьте подтверждение и нажмите «Запустить агент».
6. При рабочем сервере будет играть центральный MP3. При потере центрального потока агент попробует воспроизвести проверенный локальный кеш (при наличии заранее скачанных композиций). При восстановлении связи автоматически вернётся к серверу, останавливая резерв до запуска центрального источника.
7. Остановка — кнопка «Остановить» или закрытие окна. Никакого автозапуска Windows нет.

**Токен не записывается GUI на диск.** Для теста запускайте программу только на доверенном компьютере. Чувствительные данные не должны попадать в снимки экрана. В кэше хранятся аудиофайлы и сетка вещания, но не ключ доступа.

### Безопасность и ограничения

- Это **тест с наушниками**, не готовая система для физического школьного эфира.
- Исполнитель аудио — установленный VLC, отдельный компонент, поэтому `.exe` самостоятельный в отношении Python, но ещё **не полностью автономный медиаплеер**.
- Разрешение сервера PILOT обязательно. При отсутствии связи со свежим серверным разрешением резерв прекращается после 15 минут (параметр существующего агента).
- Кеш синхронизируется по HTTPS с SHA-256. До первой успешной синхронизации локальный резерв может быть пуст.
- Программа **не управляет усилителем, ESP32, реле, звуковым трактом школьных динамиков**.
- В текущем агенте переходы могут иметь паузы. Программа ещё не предоставляет выбор конкретной аудиокарты и не обеспечивает аппаратную защиту от двойного сигнала.
- Windows Defender/SmartScreen может предупредить о **неподписанном** исполняемом файле. Не нужно отключать антивирус глобально; для массового распространения потребуется цифровая подпись.

## ESP32 — следующий этап

Отдельный контроллер ESP32 нужен для аппаратного fail-safe (контроль присутствия ПК, heartbeat, состояние сервера и реле). До согласования безопасной электрической схемы и тестирования ESP32 нельзя автоматически разрешать включение школьного усилителя только по программному статусу. Проект GPIO, сетевого протокола и watchdog будет оформлен отдельно после проверки Windows агента в наушниках.

## Диагностика

Для проверки сервера, прежде чем запускать приложение в реальном эфире, используйте Админка → Радио → Оборудование: устройство должно быть не отозвано и иметь разрешение `PILOT`. Статусы GUI: «Центральный MP3», «Резерв», «Остановлен». Логи VLC находятся в папке кеша как `windows-central-vlc.log`. При отладке не присылайте токен и содержимое приватных файлов.
