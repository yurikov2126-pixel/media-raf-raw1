# МЧС #973 — проверка сетевых событий без включения тревоги

После #972 подтверждён учебный WAV-переход внутри центрального Windows Agent.
Этот PR добавляет следующий **беззвучный этап интеграции с платформой**:
обработка аутентифицированных START/STOP команд из уже существующего
`/api/radio-agent/agent/mchs-execution-command`.

## Гарантии

- Источник события по серверному протоколу проверяется существующим
  `validate_command` (тип, ID, срок действия, номер, флаг верификации,
  повторения 1–5, единственный повтор для отбоя).
- `EventAdmissionLedger` атомарно сохраняет последний принятый номер,
  идентификаторы и состояния. Повторное событие или устаревшая команда
  отклоняются **после перезапуска Agent**.
- Для последовательности требуется сначала `MISSILE_DANGER`, затем
  `MISSILE_ALL_CLEAR`; `STOP` сбрасывает этап даже при том же eventId.
- Повреждённый файл реестра блокирует режим (не сбрасывается молча).
- Результаты выводятся с меткой `MCHS_EVENT_ADMISSION`; поле
  `audioStarted` **всегда false**.
- В стандартном режиме Agent неподтверждённый START отклоняется **до**
  скачивания файла, а не после расходования сети и диска.
- Старые механизмы STOP/HALT для учебного аудио сохранены.

## Запуск (только тест метаданных)

После установки полного комплекта #973 в отдельную папку исходников
и с выключенным подключением к AA-300/PA:

```powershell
cd "C:\Users\andrejurikov\MEDIA-RAF-RAW-TEST\media-raf-raw1-main\radio-agent\windows"
$env:RADIO_AGENT_TOKEN = Read-Host "Введите токен устройства" -AsSecureString |
  ForEach-Object { [System.Net.NetworkCredential]::new("", $_).Password }

py .\central_playout.py `
  --vlc "C:\Program Files\VideoLAN\VLC\vlc.exe" `
  --enable-headphones-test `
  --isolated-event-admission
```

Нужно ввести `ISOLATED`, чтобы подтвердить изоляцию. В этот режим нельзя
одновременно передавать аргументы `--isolated-cycle-danger-wav` или
`--isolated-cycle-all-clear-wav`.

Agent продолжит обычное центральное вещание **на локальных наушниках**.
В случае доступной команды из платформы появится
`MCHS_EVENT_ADMISSION {...}` с `audioStarted:false`. Это **не**
доказательство доставки звука или исполнения тревоги; отсутствующие
команды не будут синтезироваться скриптом.

В конце `Ctrl+C`, затем `Remove-Item Env:\RADIO_AGENT_TOKEN`.
Токен в журналы или сообщения не вставлять.

## Чего PR НЕ делает

Не включает автозапуск сообщения опасности с Android или платформы,
не меняет API, Worker, публичный эфир, ESP32, AA-300 или физическую PA.
Отказоустойчивое *реальное* выполнение по событиям требует отдельного
этапа: разрешений, обратных подтверждений VLC/центральных пакетов, STOP
для каждого eventId и приоритетов при новой опасности.
