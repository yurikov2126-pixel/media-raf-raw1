# МЧС: испытания на штатном аудиовыходе с отключённым кабелем PA

Решение: **отдельный аудиоканал не требуется**. Испытания проводятся
на штатном выходе Windows Radio Agent, когда соединительный аудиокабель
от радио-компьютера до усилителя AA-300 физически отсоединён от
звукового выхода. Основной Agent остаётся работающим.

## Предусловия

1. Ответственный на месте подтверждает, что от радио-компьютера отключён
   именно кабель, подающий звук на усилитель/коридорные громкоговорители;
   проверена невозможность попадания учебного звука через иные маршруты.
2. Для прослушивания испытания к отключённому от PA выходу можно подключить
   локальные наушники или тестовую акустику; уровень громкости минимальный.
3. В админке явно обозначается **УЧЕБНЫЙ РЕЖИМ**; нет автоматической
   активации реальных сообщений об опасности и нет управления реле ESP32.
4. Испытание должно иметь явные команды СТАРТ и СТОП, ограничение времени,
   журнал и гарантированную возможность немедленно вернуть штатный поток.
5. После теста восстановить физическое соединение с усилителем только
   после остановки учебного воспроизведения и проверки штатного эфира.

## Важно о текущем коде

`mchs_isolated_output_pilot.py` — устаревающий ручной проигрыватель,
который создаёт **отдельный** VLC на системном выходе и требует остановки
основного Agent. Он **не решает** задачу управляемого прерывания
внутри работающего Agent и не должен запускаться параллельно.

Следующий кодовый этап: интегрировать учебное переключение
в *один* действующий аудиопроцесс Windows Agent (PROGRAM → ALERT → PROGRAM),
с управляемым сохранением позиции, защитой от повторных команд,
таймаутом и принудительным СТОП. Физически отключённый кабель
не может быть достоверно проверен программой; подтверждение даёт
ответственный оператор. Пока такого механизма нет, данная документация
не является разрешением на звуковое испытание и не доказывает
работоспособность оповещения как системы безопасности.
