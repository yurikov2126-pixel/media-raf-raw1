# ESP32 для MEDIA · РАФ · RAW — Wi-Fi Studio / безопасный этап связи

**Оборудование:** ESP32, GPIO13 (D13), одноканальный модуль с реле SONGLE SRD-05VDC-SL-C, катушка 5 В. Цель после отдельной аппаратной проверки — управление питанием усилителя через подходящий силовой коммутационный узел.

## Подготовка ESP32

1. Откройте папку `radio-agent/esp32` в VS Code + PlatformIO.
2. Скопируйте `include/secrets.example.h` в `include/secrets.h`. Имя сети уже `Studio`. Пароль Wi-Fi впишите **только в локальную копию**. Нельзя коммитить этот файл.
3. Создайте отдельный случайный секрет сопряжения от 32 символов и впишите вместо `RADIO_PAIR_SECRET`. Один и тот же секрет понадобится Windows Agent, **не передавайте его в чат, GitHub или логи**.
4. Загрузите прошивку на ESP32. На этом этапе **полностью отсоедините сеть 220–230 В от релейного модуля** и отключите усилитель.
5. Узнайте IP ESP32 из списка клиентов Wi-Fi роутера (назначьте DHCP reservation). Откройте `http://IP_ESP32/health` в браузере компьютера: должны быть `mode: SAFE_PILOT`, `relayOutputEnabled: false`.
6. Для теста локальной связи можно задать Windows Agent окружение `RADIO_ESP32_IP` и `RADIO_ESP32_SECRET` при запуске приложения. Агент будет передавать heartbeat каждые 3 секунды в своей существующей рабочей сессии. Поля `agentMode` и `heartbeatFresh` должны меняться в `/health`.
7. При отключении ПК/остановке агента через 10 секунд в `/health` будет `agentMode: DISCONNECTED`. Никаких переключений питания на этой стадии нет.

## Требования следующей стадии — после проверки электроники

- Подтверждение активного уровня 5 В релейного модуля с 3,3 В GPIO 13, его safe-off при старте ESP32 и во время сброса/потери Wi-Fi.
- Проверка силового коммутатора с учётом пускового тока усилителя, электрической изоляции, защитного автомата, кабельных вводов, отдельного ручного выключателя. Сетевую часть проверяет квалифицированный электрик.
- Центральная платформа формирует **разрешение включения за 60 секунд до утверждённой трансляции**, либо при включении Auto-DJ; ручное управление в Радио → Оборудование должно проверять роль администратора.
- Локальный резерв может продлевать **уже действующее** ограниченное разрешение при отказе интернета, но не выдавать новое бессрочное разрешение. Без связи с агентом/при истечении разрешения питание должно выключаться.
- Передаваемое поле `authorizedByPlatform` в pilot основано на существующем ограниченном серверном playback permission; **оно ещё не заменяет полноценную авторизацию включения усилителя**.
- В настоящем включающем режиме следует использовать защищённый протокол с защитой от повторных запросов, отдельным ключом на устройство и проверенной цепью управления; не превращать локальный HTTP pilot в API включения сетевой нагрузки.

**Безопасность:** не подключайте реле к силовой цепи на этапе `SAFE_PILOT`. GPIO 13 оставлен высокоимпедансным, так как фактическая полярность входа реле неизвестна и одного программного уровня недостаточно, чтобы гарантировать отключение на старте.
