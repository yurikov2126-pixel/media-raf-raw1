# PR #1008 — диагностика кратковременного OFF/ON усилителя

Проблема: один текущий ESP32 snapshot (`ON_COMMANDED` или `OFF_COMMANDED`) не показывает, **почему** во время тестового ALARM произошла кратковременная потеря команды ON. Последняя телеметрия Windows Agent уже отправляется в `POST /api/radio-agent/agent/esp32-status`.

## Что добавлено

На сервере при получении существующего авторизованного отчёта ESP32 формируется ограниченный журнал изменений (`mchs_esp32_transition_evidence_v1`, последние 150 событий):
- `COMMANDED_POWER_CHANGED`: переход командного `amplifierPower`, например `ON_COMMANDED_TO_OFF_COMMANDED`;
- `LEASE_CHANGED`: валидность разрешения реле;
- `HEARTBEAT_CHANGED`: состояние heartbeat в ESP32;
- `HEARTBEAT_COUNTER_RESET`: счётчик heartbeat уменьшился (возможный перезапуск);
- `TELEMETRY_GAP`: интервал между отчётами от одного устройства более 12 секунд;
- `REPORTER_CHANGED` и `AGENT_MODE_CHANGED`: смена источника или режима.

Состояние сохраняется в PostgreSQL под advisory lock и переживает перезапуск API. Дубликаты и отчёты со старым временем не переписывают более свежие наблюдения. События не содержат Wi-Fi секретов, токенов, полных URL или управляющих команд.

Защищённый ADMIN `GET /api/safety/missile-main-station-readiness` дополнен полем `esp32Transitions` с событиями последних 10 минут для ESP32, привязанной к диагностируемому Windows Agent. Это **только чтение**. Признаки `stabilityConfirmed:false` и `actualMainsPowerVerified:false` остаются неизменными до независимой проверки реального выхода реле и AA-300.

## Ограничения

Данные отражают **командное состояние**, а не измеренное напряжение/звук. При отсутствии сообщений или падении связи невозможно достоверно определить момент физического переключения. Сравнение периодических снимков может пропустить два быстрых перехода OFF→ON между отчётами; следующая задача — получить от ESP32 её собственные счётчики переходов и last-off-reason с монотонным временем, не меняя силовое управление.

Реальный автоматический запуск ALARM не разрешается этим PR; флаги main station, GPIO13 и правила watchdog остаются без изменений. Не проводите испытаний на подключённой сети 220 В, пока квалифицированный специалист не проверил аппаратную цепь.
