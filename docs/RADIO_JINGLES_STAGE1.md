# Radio 2.0 — Джинглы и оформление эфира (этап 1)

Администратор может выбрать существующие радиозаписи для библиотеки джинглов, задать интервал 1–30 музыкальных композиций, ограничение длины 1–60 секунд и разрешённые московские периоды (ночь, утро, день, вечер). Все настройки хранятся в Setting key radio_jingles_v1, с валидацией и обратной совместимостью. По умолчанию enabled=false.

Вкладка «Радио» содержит настройки и кнопку «Предпросмотр вставок», показывающую места предполагаемых отбивок до следующей композиции. Серверная проверка разрешает использовать только существующие RadioAsset. План исключает треки длиннее заданного лимита и не показывает вставки вне выбранного периода.

**Важно:** эта версия НЕ встраивает джинглы в PCM-поток Worker. Даже enabled=true включает только их учёт в прогнозе, но НЕ запуск аудио. Это намеренное разделение этапов: для реального эфира ещё нужны атомарное резервирование вставки, предзагрузка, контроль границ расписания, восстановление при ошибке декодера, журнал PCM и тесты наушниками. Эфирные источники, расписание передач, усилитель/PA, ESP32, Windows Agent не меняются.

После merge: открыть Радио, выбрать короткие файлы, сохранить настройки, нажать «Предпросмотр вставок». Проверить мобильный вид, светлую и тёмную темы. Не включать физические выходы ради теста.
