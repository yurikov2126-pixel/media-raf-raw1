# Политех-FM — Smart Crossfade 2.0: приёмка двух направлений

## До включения

Весь новый путь ограничен `RADIO_LIVE_SOURCE_CROSSFADE_ENABLED=true`; по умолчанию выключен.
**Не включать на основном эфире без выделенного тестового потока.** CI подтверждает сборку и воспроизводимость unit/integration-тестов, но не отсутствие щелчков у слушателей.

Для тестов использовать контролируемый Worker и валидные локальные файлы. Подготовить запись выходного MP3 на стороне слушателя (сайт и Windows Radio Agent), а по возможности PCM до encoder. Все записи помечать фактическим временем сервера и ID слотов.

## Матрица сценариев

| № | Сценарий | Ожидаемое поведение |
|---|---|---|
| 1 | AutoDJ → утверждённая программа, жёсткое начало | Один переход 1500 мс, заданное начало передачи, без повторной головы первого трека |
| 2 | Конец последнего трека программы → AutoDJ | Один переход 1500 мс, AutoDJ продолжается после уже смешанного начала |
| 3 | Полный цикл AutoDJ → программа → AutoDJ | Один непрерывный MP3-поток, корректный переход в обоих направлениях |
| 4 | «Доиграть трек до конца» | Сохраняется отложенный старт без преждевременного нового Crossfade |
| 5 | Слот отменён до overlap | Нет смешивания с отменённой передачей |
| 6 | Новый слот имеет приоритет у границы окончания текущего | Обратное смешивание AutoDJ запрещено |
| 7 | LIVE включён перед переходом или во время него | Приоритет LIVE, никакого повторного mix и зависания декодеров |
| 8 | Target-файл удалён, FFmpeg выдаёт EOF или stall | Fail-safe: нет повторно переданного PCM; ошибка видна в диагностике |
| 9 | Короткий трек / тишина до конца слота | Новый источник не начинается задним числом, при необходимости штатный fallback |
| 10 | Выключение experimental flag и рестарт тестового Worker | Возврат к прежнему маршруту; перезапуск сам может дать короткий обрыв |
| 11 | Обработка джинглов и ротации с cooldown | Нет самовольной подмены выбранного трека, unsupported transitions запрещены |

## Обязательные измерения

- Сравнить начало аудио по времени с `startAt/endAt`: зафиксировать отклонение в миллисекундах.
- Проверить waveform/PCM и прослушать ±10 с у каждой границы: щелчки, провалы, звук из другого трека, повтор головы.
- Проверить `liveSourceCrossfade.completed/fallbacks/partial/last`, `reverseHandover.mixed/last`, `reverseTargetReservation`, `lastError`.
- Для каждого сценария: фактический ID входного и выходного трека, wall-clock, длина mix в frames, статус декодеров и успешность продолжения.
- Проверить ресурсную нагрузку CPU/RSS/FFmpeg и отсутствие накопления процессов в течение не менее 1 часа.
- Проверить одинаковую слышимую программу на сайте и Windows Radio Agent (ожидаемая клиентская задержка может различаться).

## Правило допуска

Не переводить этот режим в production при хотя бы одном зафиксированном повторе кадра, паузе от переключения, неправильном приоритете расписания/LIVE или потере обязательного события. При любой ошибке сохранить запись и лог, отключить флаг на тестовом Worker и повторно проверить прежний путь. Отчёт приёмки должен содержать ссылки на реальные аудиозаписи и замеры, а не только отметку CI.
