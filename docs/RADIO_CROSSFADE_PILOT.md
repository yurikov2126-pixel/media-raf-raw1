# Radio 2.0 — Auto-DJ Crossfade (пилот)

- В Радио → Главная → Обработка звука задаётся Crossfade 0–5 секунд; по умолчанию **0 (выключен)**.
- Для Auto-DJ с двумя и более подходящими треками включается детерминированная двухдекерная схема. В зоне перекрытия FFmpeg получает два входных файла и применяет `acrossfade`. Одиночные фрагменты по-прежнему декодируются одним входом.
- Курсор учитывает Cue In / Cue Out и перекрытия; при перезапуске сервера расчёт позиции воспроизводим.
- Верхняя граница декодирования ограничена временем ближайшего утверждённого слота. К запланированным передачам crossfade не применяется.
- Исходники не изменяются. Нет управления Windows Agent, усилителем, ESP32 и PA.

## Ограничения и проверки

Это **первый пилот**. Двухвходный FFmpeg может дать слышимый зазор при декодировании/инициализации процесса; гарантированно бесшовный поток потребует постоянных декодеров и PCM-буферизации. Также normalizer текущего одноканального пути не применяется к смешанным фрагментам — оценить уровень на слух и по измерениям в следующем этапе.

1. После CI объединить PR и отдельно перезапустить серверный playout Worker.
2. Проверять только на тестовом авторизованном приёмнике через наушники.
3. Два трека длиннее 5 с, Cue In/Out, граница перехода, обновление Crossfade на очередном треке.
4. Проверить цикл последняя → первая композиция, перезапуск Worker внутри перехода, ограничения по близкой передаче.
5. Проверить fallback: один трек, короткие треки, отсутствие файла, ошибки FFmpeg, отзыв Auto-DJ.
6. Crossfade=0 должен сохранять существующую схему без перекрытия.

Никаких утверждений о прохождении физических испытаний до их фактического выполнения.
