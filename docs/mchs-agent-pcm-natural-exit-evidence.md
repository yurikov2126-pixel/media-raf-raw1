# МЧС #969 — завершение учебного PCM в действующем Windows Agent

После #968 подтверждён возврат центральной программы по свежим пакетам.
Теперь программа отличает **наблюдаемое естественное окончание локального
учебного PCM** от досрочного выхода VLC и ручной остановки.

## Наблюдения

- `LocalMonitor` считает байты, действительно переданные в VLC.
- Отдельно фиксирует EOF от учебного PCM upstream, ограничение размера
  и ошибки транспорта; начало новой сессии обнуляет доказательства.
- При выходе VLC с кодом 0 после EOF без ошибок появляется
  `MCHS_LAB_PCM_END_EVIDENCE PCM_EOF_AND_VLC_EXIT_OBSERVED`.
- Досрочный выход VLC, тайм-аут, обрыв или ручной STOP никогда не
  считаются естественным окончанием.
- Во всех случаях Agent по прежнему возвращается к нормальной программе;
  затем наблюдается `MCHS_CENTRAL_RETURN_CONFIRMED` или
  `MCHS_CENTRAL_RETURN_UNCONFIRMED`.

## Важная граница

Это только свидетельство локального PCM EOF + корректного завершения VLC.
`fullAlarmCompletionVerified:false` — фиксированное значение: оно
не доказывает полного воспроизведения оригинального ALARM, точного
количества повторов или одновременного завершения Worker/Agent.
Для полной проверки нужен event-bound receipt Worker и отчёт Agent v2,
которые уже отдельно реализованы. Программный EOF не доказывает
акустическую слышимость в наушниках или PA.

Испытание допустимо только с физически отключённым AA-300 и всеми
альтернативными каналами PA. PR не включает публичную тревогу,
не запускает Android-события и не управляет ESP32.

```powershell
python -m unittest -v test_mchs_lab_end_evidence test_mchs_central_return_monitor
```
