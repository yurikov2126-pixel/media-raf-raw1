# Radio 2.0 — этап обработки звука (DSP, первый PR)

## Область изменений
Серверный `radioPlayout.js` умеет применять к **новому декодируемому треку** опциональный FFmpeg audio filter. Настройки доступны администратору на главной странице «Радио», сохраняются в существующей таблице Settings. По умолчанию **отключены**; существующий поток продолжает работать без обработки.

- `loudnorm` (одно прохождение): целевая громкость от -24 до -12 LUFS, пик -6…-1 dBTP. Это **не** точное двухпроходное измерение LUFS; субъективно проверяйте материал через наушники.
- Fade In / Fade Out: опциональный плавный старт и окончание отдельного декодируемого трека (0–3000 мс). **Это не crossfade**: для перекрытия двух треков потребуется другая схема декодирования и микширования.
- Обрабатываются как запланированные передачи, так и дорожки Авто-DJ; исходные файлы не изменяются.
- Server worker health `version: dsp-v1` и `audioProcessing` отражают последнюю применённую конфигурацию.

## Проверка
1. После CI и объединения перезапустить **отдельный** `mediaraf-radio-playout.service` по утверждённой процедуре. Изменения API сами Worker не обновляют.
2. В админке Радио → Главная → Обработка звука: сначала оставить выключено. Проверить, что поток не изменился.
3. На тестовом приёмнике **только через наушники**, без PA/усилителя/ESP32: включить -16 LUFS / -2 dBTP, fade=0, сохранить, дождаться нового трека и проверить Worker health.
4. На мягком материале убедиться в отсутствии слышимых искажений, сравнить разные уровни источников.
5. Отдельно проверить fade 250–500 мс на тестовой композиции; возле запланированной передачи fade не должен отложить старт по расписанию.
6. Отключить обработку в админке и дождаться следующего трека: прежний поток восстанавливается.
7. Проверить тёмную/светлую темы, мобильную страницу и права (только ADMIN).

## Ограничения
Нет точной offline LUFS-аналитики, ReplayGain, edit point / Cue In/Out, настоящего crossfade и общей системы микширования нескольких источников. Эти функции требуют отдельного PR, чтобы не нарушить точный старт эфиров. Никакой автоматической активации обработки или физических звуковых выходов в этом PR нет.
