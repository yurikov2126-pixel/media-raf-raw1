# Учебная запись МЧС в общем радиопотоке (закрытая пилотная функция)

По умолчанию **выключено**. В отличие от старой `worker-lab` сессии этот режим заменяет PCM непосредственно перед общим MP3-кодировщиком. Поэтому один и тот же кодированный сигнал получают сайт и Windows Radio Agent. Он не включает усилитель и не запускает настоящую тревогу.

## Подготовка

1. Загрузить аудиозапись в радиобиблиотеку и назначить категорию **ALARM**. Для первого опыта использовать явно учебную запись, не имитирующую настоящую тревогу. Отдельный raw PCM-файл **не требуется**.
2. В окружении Radio Worker включить только `RADIO_MCHS_TRAINING_STREAM_ENABLED=true`, перезапустить Worker в техническое окно. По умолчанию режим выключен.
3. В админке открыть «Учебное переключение основного радиопотока», выбрать существующую запись из категории **ALARM**.
4. Проверить присутствие оператора, уведомление аудитории и доступную физическую остановку усилителя. Запустить запись вручную.
5. Worker сам декодирует выбранный файл через FFmpeg в PCM 48 kHz stereo s16le, берёт не более первых 10 секунд и подаёт перед общим MP3-кодировщиком.
6. STOP отменяет подмену, автоматическое завершение происходит по длине записи или через 10 секунд. При этом обычная программа продолжает работу. Из-за MP3-буферов акустическое прекращение не мгновенное.
7. После испытания отключить `RADIO_MCHS_TRAINING_STREAM_ENABLED=false`.

## Границы

- Это **только ручной учебный запуск**, отдельный от автоматических сообщений МЧС. Не подключать реальные источники MCHS ingest к этому endpoint.
- Лабораторные `START/INTERRUPT/RESUME` продолжают управлять только изолированной тестовой сессией и не влияют на общий поток.
- Включение через сервер не включает AA-300/ESP32. Меры физического контроля и предупреждение аудитории остаются обязанностью ответственного оператора.
- Источник AutoDJ может продвинуться в процессе учебной вставки; точное восстановление позиции исходного трека этим этапом не гарантируется.
- Не использовать как рабочую систему оповещения: нет подтверждения акустической доставки, независимого приоритетного аппаратного разрыва и сертифицированного канала.
