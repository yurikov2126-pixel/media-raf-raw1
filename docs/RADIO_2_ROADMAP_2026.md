# MEDIA · РАФ · RAW — Radio 2.0: актуальная дорожная карта
Состояние на 18 октября 2026. Продукт: централизованная автоматизация студенческого радиовещания с удалённой подготовкой эфира, одним серверным плейаутом и автономным резервом на радиокомпьютере.

## Инвентаризация (по текущим файлам основного репозитория и испытаниям)

|---|---|---|

| Прямой эфир в серверном микшере | Не реализовано | Приоритетная архитектурная работа |

> Не путать «пилот проверен» с production-ready. Наличие UI/endpoint не означает прохождения отказоустойчивых испытаний.

## P0 — ближайшие работы без оборудования (сервер / веб)
1. **Валидатор эфирной сетки:** визуально показывать перекрытия, пустые интервалы, длительность передач и нехватку музыки; до сохранения предупреждать о конфликтах; не менять утверждённую сетку молча. Тесты точного московского времени, UTC-границ и DST-independent logic.
2. **Медиаинспектор при загрузке:** длительность, кодек, частота дискретизации, число каналов; анализ тишины, некорректных записей и loudness с EBU R128/ITU BS.1770; предупредить о клиппинге. Не нормализовывать оригинал без осознанной настройки.
3. **Now/Next и подробный экран управления эфиром:** активная запись, countdown/offset, следующий материал, источник PRIMARY/LOCAL/SILENCE, разница план/факт, предупреждения и журналы ошибок. Пользовательские роли: оператор / редактор / администратор.
4. **Серверный audit/as-run:** фиксировать начало/конец фактического воспроизведения, track/slot/source, ошибки, перебои; разграничить запланированное от действительно доставленного на устройство.
5. **Тесты производительности Worker:** границы треков, переполнение stdout, несколько приёмников, source hung, большие файлы, непрерывный кодер, отсутствие аудиофреймов при TCP=200.

## P1 — полноценный движок музыкальной автоматизации
6. **Почасовые шаблоны clock:** музыкальные блоки, джинглы, новости, идентификаторы станции, резервные заполнители, точные временные маркеры.
7. **Музыкальные ротации/правила:** жанр, исполнитель, композиция, min separation, день/неделя, приоритет, запрет близких повторов, чередование категорий; детерминированная генерация с предварительным просмотром.
8. **Cue points и segue editor:** intro/outro/start/end, автоудаление цифровой тишины на границах, регулируемый crossfade, fade-in/fade-out, backtiming. Не обрезать непомеченный музыкальный материал автоматически без прослушивания.
9. **Джинглы / beds / sweeper / cartwall:** быстрая панель воспроизведения, категория, ducking, права операторов.
10. **Voice tracking и запись подводок:** дистанционная запись, предпрослушивание перехода с двумя соседними композициями, согласование, публикация к часу.

## P2 — центральная студия и внешние устройства
11. **Серверный арбитр источников:** плановая запись → live WebRTC микрофон → резерв/тишина; один микшер для всех приёмников. Экстренное оповещение должно оставаться отдельной аппаратной цепью.
12. **Windows Agent:** нативный вывод, надёжное кэширование, контроль устройства, failover по текущему серверному курсору, диагностика, безопасный автозапуск, обновления.
13. **ESP32/выходы:** состояние канала, heartbeat, строгое разрешение управления, реле по безопасной схеме только после физического тестирования с инженером.
14. **Мониторинг и recovery:** heartbeat, превышение задержки, тишина/клиппинг, деградация сети, уведомления операторам, тесты 24–72 ч, отчёт об инциденте.
15. **Запись эфира, экспорт и архив:** реальные as-run логи, записи с ограничениями доступа/срока хранения, отчёт о передаче.

## P3 — дополнительная функциональность
16. Редакционные задания/Академия: подводки, запрос музыкального оформления и согласование роликов через существующую платформу.
17. Веб-плеер (публичный только при отдельном разрешении/лицензионных и инфраструктурных решениях), подкаст/повтор передачи, метаданные now-playing и обложки.
18. Станционные метрики, качество сетки, аудит отказов, резервные профили, многоканальные зональные сценарии только если действительно понадобятся.
