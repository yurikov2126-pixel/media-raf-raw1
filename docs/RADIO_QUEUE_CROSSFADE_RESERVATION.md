# Radio 2.0 — резервирование двух дорожек событийной очереди

Этот PR — **этап подготовки** безопасного Crossfade в строгом Auto-DJ. Он добавляет чистую функцию `reserveCrossfadePair`, которая выбирает две разные записи, проверяет обе на ограничения cooldown по серверной истории, но **не начинает воспроизведение и не записывает события**. Отдельная функция `safeCrossfadeDuration` ограничивает перекрытие Cue-длительностью источников и временем до следующей передачи по расписанию.

В случае единственной доступной композиции план имеет состояние SOLO, в случае отсутствия доступных — EMPTY; никакого обхода строгого cooldown не происходит.

Двухдекерный Crossfade в реальном Worker **пока не активируется**. Для его подключения в следующем PR нужны: закрепление выбранной второй дорожки до конца первого трека, предзагрузка двух декодеров, непрерывная PCM-шкала и журналирование обеих дорожек по фактически полученному PCM. Вносить эту интеграцию без серверных тестов нельзя.

Зависимость: PR основан на ветке PR #412, где собраны #413–#416. **Сначала объединить #412 в main, затем перенаправить этот PR на main** и повторно проверить CI. Не подключать PA, усилитель, ESP32 и реле. Тесты воспроизведения только через наушники.
