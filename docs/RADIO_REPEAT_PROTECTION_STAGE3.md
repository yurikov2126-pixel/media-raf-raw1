# Radio 2.0 · Этап 3 · Защита от повторов исполнителей

## Реализация
Настройка **«Минимум других композиций между песнями одного исполнителя»** (0–5) и поле исполнителя для каждой записи доступны в Радио → Главная → Музыкальная ротация. По умолчанию интервал равен 0, прежний эфир не изменяется.

После ежедневного детерминированного перемешивания внутри выбранного московского периода Auto-DJ старается переставить записи так, чтобы песни с одинаковым исполнителем не шли слишком близко, **в том числе через границу последней/первой композиции цикла**. Сравнение имени без учёта регистра. Треки без исполнителя считаются неизвестными, совпадение имени по названию файла не угадывается.

Настройка влияет только на Авто-DJ при включённой умной ротации. При невозможности выдержать интервал (например, библиотека содержит слишком много песен одного исполнителя) воспроизведение не отключается: выбирается порядок с меньшим количеством нарушений. Количество оставшихся конфликтов возвращается во внутреннем `rotationPlan().artistViolations`.

## Ограничения и дальнейшие задачи
- Это защита от **близких повторов исполнителей в порядке композиций**, а не полная история того, что действительно услышал слушатель. Нет пока временных интервалов в минутах или журнала фактического эфира.
- Каждая позиция плейлиста обычно проигрывается один раз за полный цикл. Если одна аудиозапись включена в плейлист несколько раз, отдельный запрет таких дублей ещё не реализован.
- Граница двух московских музыкальных периодов может породить близкий повтор исполнителя; для сквозной защиты понадобится журнал последних исполнителей и согласование с детерминированным курсором.
- Cue/Crossfade и точные начала запланированных передач не меняются.
- Поля сохраняются в Settings без миграции; старые конфигурации совместимы.

## QA
1. CI server lint и тесты, client test/build.
2. Не включать новый интервал в активном эфире до проверки наушниками.
3. Два трека одного исполнителя с другими песнями между ними; проверить ограничение 1/2/3.
4. Проверить цикл последняя → первая, смену дня и четыре московских периода.
5. Проверить малую библиотеку, неизвестного исполнителя, перезапуск Worker, Cue/Crossfade и ближайший слот передачи.
6. После merge отдельно перезапустить серверный Radio Worker. PA, реле, усилитель и ESP32 не подключать.
