# Управление усилителем в Эфирном пульте и Windows Agent 0.3.2

## Интерфейс платформы
«Радио → Эфирный пульт → Усилитель · ESP32» отображает свежий статус ESP32, режим AUTO/MANUAL, запрос включения и кнопку аварийной блокировки. Администратор может изменить режим и ручной запрос. Действия сохраняются с записью в AdminAction. Автоматическое правило формирует запрос за 60 секунд до одобренной передачи и при включённом Auto-DJ.

ВАЖНО: в этой версии это **состояние политики**, а не физическая команда реле! В /amplifier поле physicalRelay=NOT_CONTROLLED и hardwareReady=false. Никакого включения GPIO13, HTTP-команды на реле и коммутации сетевого питания не реализовано.

## Windows Radio Agent
Новое компактное окно (780×615) с вкладками «Эфир», «Подключения», «Настройки», тёмное оформление. Вкладка подключений показывает IP ESP32, статус сопряжения, статус отправки на сайт, сервер/VLC и отдельные токены. На вкладке настроек находится Windows-автозапуск и обновления.

## Выпуск версии 0.3.2
После объединения PR в main создать тег `radio-agent-v0.3.2` строго от свежего коммита main. GitHub Actions проверит AGENT_VERSION и прервёт выпуск, если номер не совпадает. Только после успешного релизного workflow версия становится доступной встроенному обновлятору.

## Требования к физическому включению
Перед разрешением физического GPIO13 требуется проверить совместимость управляющего входа 5В релейной платы с 3.3В ESP32, активный уровень и поведение при загрузке/сбросе, защиту цепи сетевого усилителя с учётом пускового тока и ручного выключателя. Это должен проверить квалифицированный специалист. Отсутствие подключённого аудиосигнала не снижает риски коммутации 220В. Последующая стадия: отдельное аппаратное разрешение, подписанные ограниченные по времени команды, контроль Windows Agent и отказобезопасное OFF.
