# Политех-FM — корреляция завершения ALARM на двух каналах

## Цель этапа

После PR #955–958 Worker и Windows Agent умеют отдельно сообщать о
завершении ALARM. Этот этап добавляет единый **read-only** критерий для
проверки *одного и того же* события на обоих выходах.

Для положительного результата необходимо одновременно:

- точное совпадение `eventId`, типа, ALARM-файла и числа повторов;
- Worker подтверждает `FILE_COMPLETED`, `active=false`,
  `completedRepeats=repeats` и переход `revision=startRevision+1`;
- Windows Agent сообщает v2 `naturalCompletion=true`, отсутствие
  запущенного процесса, отсутствие ошибки и полное число повторов;
- обе записи относятся к свежему времени и не являются повтором
  свидетельства от другого события.

**Важная граница:** текущий GET `/mchs-training-stream` возвращает
состояние *общего* Worker, но не привязывает его к идентификатору
Android-события или стартовой ревизии. Его нельзя считать
подтверждением подлинного двухканального ALARM только потому, что
совпали файл и число повторов. Для положительной оценки будет нужен
журнал завершённых event-bound сессий Worker.

## Диагностика администратора

`GET /api/safety/missile-natural-completion` возвращает:

- `workerComplete` / `agentComplete`;
- `bothNaturallyCompleted`;
- объясняющие `holds`;
- наличие Worker и версию отчёта Agent;
- явный признак, что endpoint не включает автоматический публичный эфир.

Маршрут не имеет побочных действий на аудиотракте, не вызывает
START/STOP и не меняет исполнение.

## Проверки

```sh
cd server
node --test tests/mchsNaturalCompletionEvidence.test.js \
 tests/mchsAgentPlaybackReport.test.js \
 tests/mchsVerifiedWorkerTransport.test.js
```

Эти проверки включены в серверный CI.

## До ввода в эксплуатацию

Следующим отдельным шагом должен стать event-bound журнал Worker и
аттестованный источник уведомлений Android. Даже положительные
записи локальных программ не заменяют фактической проверки
звуковоспроизведения на конечных громкоговорителях.

Нормальный процесс по-прежнему не требует от оператора команды STOP:
`FILE_COMPLETED` означает автоматическое освобождение эфира.
