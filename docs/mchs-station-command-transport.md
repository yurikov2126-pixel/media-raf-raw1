# МЧС — внутренний транспорт сервер → Radio Worker (этап после PR #999)

Добавлен самостоятельный локальный транспорт `requestMchsStationSession` и
авторизованный Worker-маршрут `/mchs-station-session`. Это техническая
возможность связать центральный координатор с уже реализованным
`mchsStationPcmExecutor`, а не автоматический запуск настоящих тревог.

## Контракт

- `GET /mchs-station-session` — внутренний status, даже когда START отключён.
- `POST` с `START`: `eventId`, `eventType` (`MISSILE_DANGER` /
  `MISSILE_ALL_CLEAR`), `assetId`, `repeats`, `occurredAt`.
  Команда ограничена по возрасту, привязана к категории радиоактива
  `ALARM`, проверяется Worker и передаётся отдельному priority PCM
  исполнителю. Отбой воспроизводится один раз.
- `POST` с `STOP` может завершить только активную сессию с тем же
  `eventId`, включая незавершённую подготовку WAV. Само штатное окончание
  файлов STOP не требует.
- Сохранены подтверждения `PREEMPTING → PLAYING → RESUMING → COMPLETE`.
  Режим радио и статус возвращаемого источника наблюдаются независимо.
- Параллельный запуск учебного и штатного PCM-источника блокируется.

## Авторизация и статус внедрения

Оба флага по умолчанию `false`:

- `MCHS_MAIN_STATION_COORDINATOR_ENABLED` у Express API
  (не включает внешние маршруты);
- `RADIO_MCHS_STATION_COMMANDS_ENABLED` у Radio Worker (разрешает
  внутренний авторизованный START в **реальном общем эфире**).

Не изменять флаги на production до полного end-to-end допуска.
Нет внешнего публичного API для START, нет связи из Android intake и
нет управления GPIO13/ESP32. Worker проверяет
`x-radio-worker-secret`, доступен через loopback, декодирует WAV в
48kHz PCM16 stereo; не принимает произвольные пути к файлам.

**Важно:** Worker использует общий encoder сайта и Agent, поэтому
разрешённый START действительно может прервать основной эфир.
Отдельного безопасного флага для физического усилителя этот маршрут
не создаёт: линия колонок должна оставаться отсоединённой до
аппаратной приёмки.

Следующий шаг: подключить вызывающий серверный координатор к проверенным
Android-событиям, обеспечить долговременную дедупликацию,
наблюдаемость двух выходов и отдельный аппаратный readiness gate
ESP32. Проверить отсутствие неожиданных OFF/ON и HTTP 502.
Никакого автоматического реального объявления этот PR не запускает.
