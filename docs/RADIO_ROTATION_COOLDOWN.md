# Radio 2.0 — история эфира и приоритет неповторяющихся записей

**Зависимость:** этот PR построен на ветке `feature/radio-playout-history-412` (PR #412). Сначала объединить #412, затем перенаправить данный PR на `main`.

В админке музыкальной ротации добавлен интервал 0–240 минут. При формировании очередной московской музыкальной программы Auto-DJ сверяет последние события сгенерированного PCM и переносит недавно прозвучавшие записи в конец очереди. История берётся из server worker (не из прослушивания на устройстве). Порядок фиксируется до следующего периода, чтобы новая запись в истории не меняла позицию музыкального курсора посреди трека, в том числе во время Crossfade. При выключенной ротации функция не применяется.

Это **мягкая приоритизация**, а не гарантированный запрет повторов на N минут: на маленьком плейлисте музыка повторится, а при завершении цикла и на смене периода могут возникнуть совпадения. На данном этапе нет автоматического удаления или пропуска треков: это могло бы нарушить детерминированную временную сетку. Для строгой защиты потребуется отдельная event-driven очередь воспроизведения, а не расчёт позиции по часам.

Проверка: совместимость настроек старого формата, конфигурация 0/15/60/240 минут, окончание периода, рестарт Worker, Cue/Crossfade и точные начала передач. Тестировать только через наушники. Windows Agent, ESP32, усилитель, реле, школьная PA не меняются.
