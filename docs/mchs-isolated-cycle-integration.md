# МЧС — комплексная изолированная репетиция ALARM

Этот этап проверяет ранее реализованные алгоритмы одним тестовым процессом,
не подключая их к реальному Android-источнику или публичной трансляции.

## Последовательность

1. При условии `mode=ISOLATED_TRIAL` и подтверждённой изоляции выходов
   запускается учебная опасность через существующий двухканальный исполнитель.
2. Radio Worker и Windows Agent должны **каждый** подтвердить начало и
   самостоятельное естественное окончание всех повторов.
3. Отдельный read-only механизм подтверждает, что Worker вернулся к
   обычной программе и Windows Agent **после окончания обоих ALARM**
   снова получает свежий центральный звук.
4. Только после успешной проверки возврата учебный сценарий переходит
   к отдельному событию отбоя, которое проигрывается один раз.
5. Отбой также требует двух завершений и программного восстановления.
6. Штатный путь не отправляет STOP. При сбое запуска или воспроизведения
   прежний исполнитель выполняет ограниченную компенсационную остановку.

## Покрытие тестами

- 4 полных повтора опасности → 1 отбой → возврат к радио
- Нет лишних команд STOP в штатном сценарии
- Изоляция выхода обязательна; запрос включить публичный эфир отклоняется
- Сбой Windows Agent до начала или в процессе ALARM
- Подмена события в отчёте Agent
- Потеря диагностического канала возврата
- Центральный аудиопакет пришёл **между завершением Worker и Agent**:
  он не считается возвращением к программе
- Нет перехода к отбою, если опасность либо её программное восстановление
  остались неподтверждёнными

## Границы интерпретации

Это интеграционные **тесты программных компонентов с подставными каналами**,
не испытание реальной акустики. Они не вызывают Worker HTTP START, не
отправляют команды на Windows Agent и не включают PA. Даже полностью
успешная репетиция не подтверждает происхождение официальной тревоги,
фактическую слышимость на громкоговорителях или эксплуатационную готовность.

Успешное завершение программной сессии отличается от состояния
`bothSoftwareChannelsResumed`; последнее требуется дополнительно.
