# macOS Radio Agent — графический пилот

## Статус
Графический клиент на Tkinter для macOS: проверка токена, синхронизация утверждённой сетки и файлов, текущая/следующая передача, журнал и явный запуск/остановка тестового воспроизведения. Windows-версия будет построена на этой общей схеме после проверки пилота.

**Важно:** это исходный код, а не подписанный/нотариально заверенный .app. Запуск через Python. Не использовать для обязательного оповещения и не подключать к усилителю или общей акустике.

## Предварительные требования на Mac
- Установить актуальный Python 3 с графической поддержкой Tkinter. Рекомендуется официальный установщик с https://www.python.org/downloads/macos/ . Проверить: `python3 -m tkinter` — откроется тестовое окно. Если Tkinter отсутствует, нужна версия Python с Tk; установка произвольных pip-пакетов проблему не решит.
- Установить VLC для macOS с https://www.videolan.org/vlc/ и переместить `VLC.app` в `/Applications`. Проверьте путь `/Applications/VLC.app/Contents/MacOS/VLC`.
- На сервере уже должны быть развёрнуты этапы Radio Agent и pilot (PR #362, #363) с миграциями для RadioDevice и playbackAllowed. **Этому PR не нужны новые серверные зависимости и Prisma-миграции**.
- Создать отдельный токен *для Mac*, не переиспользовать токен Windows: ADMIN → Радио → Оборудование → Зарегистрировать радиокомпьютер. Не присылать токен в чат, не хранить в исходном коде.

## Первый запуск
Скопировать из GitHub в одну папку на Mac три файла:
- `radio-agent/macos/gui.py`
- `radio-agent/macos/sync_agent.py`
- `radio-agent/macos/pilot_playout.py`

Открыть Terminal в этой папке:

```bash
python3 -m tkinter
python3 gui.py
```

В окне вставить уникальный токен и нажать **Проверить связь**, затем **Синхронизировать файлы**. Файлы сохраняются в `~/Library/Application Support/MediaRafRadioAgent/cache`, расписание — `snapshot.json`.

## Тест звука
1. Подключите **только наушники** (или изолированные тестовые колонки), установите низкий уровень громкости. Не подключайте AA-300 / ESP32.
2. В веб-админке для Mac разрешите тестовый эфир.
3. В приложении нажмите «Проверить связь», убедитесь, что статус «Тестовый эфир разрешён».
4. Запланируйте короткую тестовую передачу на 5–10 минут вперёд по московскому времени. Выполните синхронизацию.
5. Нажмите «Включить тестовое воспроизведение» и подтвердите предупреждение.
6. Передача запускается *только если* агент увидел её начало в первые 10 секунд; опоздавшие старты и уже отмеченные ID слотов пропускаются. Кнопка «Остановить» завершает группу процессов приложения и VLC.
7. После теста нажмите «Остановить», отключите разрешение в админке и закройте приложение.

## Ограничения пилота
- Окно показывает текущую/следующую передачу по загруженному snapshot; оно не является подтверждением фактического звучания.
- Полноценное автономное воспроизведение без сервера пока не поддерживается; связь проверяется регулярно.
- Внутри текущей дорожки удалённое отключение через админку не прерывает VLC мгновенно; используйте локальную «Остановить».
- Токен хранится только в оперативной памяти процесса и наследуется дочерним процессом; локальных файлов конфигурации с токеном нет.
- Нет выпуска .app, подписи Apple Developer, фоновое выполнение без сессии пользователя не настраивается.
