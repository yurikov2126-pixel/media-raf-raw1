# Radio 2.0 — Cue In / Cue Out, безопасный первый этап

## Назначение
В админке Радио → Главная доступен редактор точек Cue для аудиотеки.
Cue In и Cue Out хранятся как миллисекунды в настройках станции, не меняя загруженный аудиофайл. На этом этапе применяются **только к музыке Авто-DJ внутри серверного playout**.

## Почему расписание исключено
Слоты по сетке рассчитываются по исходным длительностям файлов. Обрезка запланированных материалов без единого пересчёта длительности на сервере, в агентах и БД изменит временную сетку. Поэтому к запланированным передачам Cue пока не применяются. Запланированные эфиры сохраняют приоритет и точное время старта.

## Проверка
- При отключённом Auto-DJ эфир остаётся без изменений.
- В редакторе Cue указать, например, In=5.0 с, Out=55.0 с для трека 60 с; проверить на тестовом серверном потоке в наушниках, что играет 50-секундный фрагмент.
- Проверить переход к следующей композиции и возврат по циклу; начало запланированной передачи не должно задерживаться.
- Проверить ошибки: отрицательное начало, окончание позже исходной длительности, фрагмент менее секунды.
- После применения PR перезапустить отдельно Radio Worker, как и для предыдущего этапа DSP.

## Ограничения
Crossfade/перекрытие треков пока не реализовано. Для настоящего crossfade потребуется отдельная двухдекодерная схема с буферизацией PCM и сохранением точных границ сетки. Проверку через PA, усилитель или ESP32 проводить нельзя; первоначальный тест — только наушники.
