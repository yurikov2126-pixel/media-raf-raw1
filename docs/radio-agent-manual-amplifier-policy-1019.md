# PR #1019 — ручное включение усилителя в production

## Обнаруженная неисправность

Администратор выбирал **MANUAL** и включал усилитель в «Эфирном пульте». Сервер выдавал зарегистрированному Windows Agent `permit:true`, но `RadioAgentApp.power_tick()` всегда передавал ответ в `allowed_power()`, который запрещал команду ON при остановленном локальном радиоплеере, нажатой кнопке Stop или отсутствии свежего аудиопотока. Это объясняет ситуацию «сервер разрешает, вручную не включается» даже с работающими ESP32 и Agent.

## Исправление

Введена разница между двумя явно различными режимами:
- **AUTO**: как и прежде, нужен свежий `permit:true` сервера **и** запущенный Agent/свежий звук. Локальный Stop и 30-секундный таймаут аудио запрещают питание.
- **MANUAL**: только при **свежем** ответе авторизованного `GET /api/radio-agent/agent/amplifier-intent` с `permit:true`, `policyMode:MANUAL`, `reason:Ручной режим`, `emergencyOff:false`, `hardwareExpected:POWER_CONTROL_V1` и совпадающим IP зарегистрированной ESP32 разрешение не зависит от Start/Stop аудио. Требуется локальная включённая аппаратная галочка (hardware arming). Серверное OFF, отключение разрешения Device, аварийное OFF или снятая аппаратная галочка всегда приводят к OFF.
- **Изолированные пилоты**: новая логика не применяется.

Сохранены подписанные HMAC команды, неизменная TTL lease 8000 мс и аппаратный watchdog. Локальное выключение радио не отключает усилитель в MANUAL, пока администратор явно разрешает питание — это ожидаемая семантика ручного режима. Закрытие Windows Agent или истечение lease оставляет ESP32 в fail-safe OFF.

## Проверка

После объединения и установки нового EXE проверьте «Эфирный пульт → Усилитель»:
1. Отключите громкоговорящую/силовую нагрузку на время аппаратного испытания и убедитесь в исправности электромонтажа.
2. В Agent настройте правильную ESP32, токен радио и аппаратный допуск.
3. Переведите усилитель в **MANUAL** и задайте **ВКЛ** при остановленном воспроизведении. Допуск должен быть виден как `GPIO13 ON`, даже без музыки.
4. Выберите **ВЫКЛ**. GPIO13 должен немедленно получить подписанное `permit:false`, а журнал показать `SIGNED_PERMIT_FALSE`.
5. Верните AUTO и проверьте: без эфира нет нового включения; при разрешённом радио — штатное управление.

Никакой автоматической тревоги, смены прошивки, рабочего PCM Worker или 220-В цепи этот PR не запускает. Командное состояние GPIO13 не доказывает наличие 220 В на усилителе.
