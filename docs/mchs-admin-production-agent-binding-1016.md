# PR #1016 — выбор рабочего Windows Radio Agent из админки

## Задача

До этого этапа production-диагностика МЧС использовала переменную `MCHS_MAIN_STATION_AGENT_DEVICE_ID` на сервере. Это требовало SSH/изменения окружения для выбора обычного радиокомпьютера.

Теперь в «Экстренное оповещение → Тракт оповещения» администратор может выбрать зарегистрированный Windows Radio Agent из списка. Список загружается с сервера, содержит только неотключённые `radioDevice`; их токены авторизации и секреты ESP32 не показываются. Привязка действует исключительно для чтения статуса радиостанции, истории GPIO13 и диагностики Windows Agent, не для новых команд реле или оповещений.

## Безопасность и порядок приоритетов

1. `MCHS_MAIN_STATION_AGENT_DEVICE_ID` в окружении сервера — максимальный приоритет, менять его через интерфейс **нельзя**.
2. Сохранённый администратором идентификатор зарегистрированного активного `radioDevice` в `mchs_main_station_agent_binding_v1`.
3. Устаревший `MCHS_AGENT_LAB_DEVICE_ID` — только совместимость, с явным предупреждением.
4. Если ничего не задано, никакой компьютер не выбирается сам собой.

Маршруты `GET/PUT /api/safety/missile-main-station-agent-binding` доступны только ADMIN. PUT проверяет формат ID и существование неотключённого RadioDevice. В случае заданного ENV возвращается HTTP 409. В настройке сохраняется только ID — **не** токен `rr_` и не секрет управления ESP32. После сохранения карта диагностики обновляется, перезапуск Node API не требуется.

## Что проверить

- Открыть вкладку диагностики с правами ADMIN: в списке есть зарегистрированные неотключённые радиокомпьютеры.
- Выбрать Windows Agent, который физически связан с вашей ESP32, нажать «Сохранить».
- Убедиться, что показывается именно он и что старое предупреждение о лабораторной привязке исчезло.
- Если задан серверный ENV, настройка должна быть заблокирована, а ENV иметь приоритет.
- При отсутствии/устаревшей телеметрии ESP32 диагностический экран должен по-прежнему показать отсутствие подтверждения.
- Если выбирается другое устройство, старый журнал GPIO13 не должен подставляться автоматически.

**Важно:** выбор устройства не свидетельствует об исправности физического реле, наличии 220 В или слышимости громкоговорителей. Никаких ALARM, STOP, MANUAL или AUTO команд эта настройка не отправляет. При проверке силовых цепей соблюдайте отключение нагрузки и электробезопасность.
