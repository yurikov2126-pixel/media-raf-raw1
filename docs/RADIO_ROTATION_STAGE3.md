# Radio 2.0 · Этап 3 · Категории и музыкальная ротация

## Что реализовано
Авто-DJ может применять музыкальные категории ENERGY, POP, CALM, INSTRUMENTAL, OTHER. В админке «Радио → Главная → Музыкальная ротация» доступны категории по файлам и наборы разрешённых категорий для четырёх интервалов (Москва UTC+3): ночь 00–07, утро 07–11, день 11–18, вечер 18–24.

Правила по умолчанию **выключены**. Настройки хранятся в таблице Setting, миграция не нужна. Внутри каждого периода музыка упорядочивается детерминированно по дате/ID, поэтому после перезапуска Worker не начинает каждый раз с первой записи и не выбирает один трек случайно на каждом запросе. Между полными циклами возможен повтор последнего/первого трека; полноценное отслеживание истории исполнителей — следующий подэтап после появления надёжных музыкальных метаданных.

Пустая выбранная категория использует разрешённые записи базового плейлиста, чтобы музыка не прекращалась. Граница периода обрывает текущий музыкальный сегмент и создаёт новую музыкальную программу; позднее можно добавить мягкий перенос на конец композиции. **Запланированные эфиры всегда приоритетны**.

## Проверка
1. Оставить ротацию выключенной, проверить прежний Auto-DJ и Crossfade.
2. Распределить записи по категориям; включить настройку только на тестовом приёмнике и прослушать в наушниках.
3. Проверить четыре московских периода и переходы 07:00, 11:00 и 18:00; сверить категорию с настройками.
4. Проверить границу утверждённой передачи: точный старт, восстановление Auto-DJ.
5. Проверить перезапуск отдельного server playout Worker в середине периода.
6. CI, backend test, сборка frontend; после merge отдельно перезапустить Worker.

Запрещено подключать PA/усилитель/ESP32 на этой стадии. Windows Agent и разрешения физических выходов не меняются.
