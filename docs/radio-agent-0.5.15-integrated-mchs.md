# Windows Radio Agent 0.5.15 — встроенные автоматические оповещения МЧС

С версии **0.5.15** отдельный `start_mchs_test.py` для тестирования
Android → сервер → Windows Agent в наушниках не нужен. Используется
обычный `MediaRafRaw-RadioAgent.exe`, собранный через `gui.py`.

## Включение в EXE

1. Остановите прежний процесс `py .\\start_mchs_test.py`, иначе на одном
   устройстве будут работать два конкурирующих аудиопроцесса.
2. Запустите `MediaRafRaw-RadioAgent.exe` версии 0.5.15.
3. В «Подключения» убедитесь, что настроены HTTPS-сервер, токен
   радиокомпьютера (может загружаться из DPAPI) и установлен VLC.
4. Во вкладке «Эфир» включите «Тест в наушниках» и
   «Принимать Android-события изолированно».
5. Выберите **два разных** учебных PCM WAV: «Ракетная опасность» и
   «Отбой ракетной опасности». Пути к WAV сохраняются в локальных настройках,
   токен сохраняется только в DPAPI при соответствующей опции.
6. Физически отсоедините все PA/AA-300 аудиолинии и убедитесь, что
   «Разрешить физическое управление реле» отключено.
7. Нажмите «Запустить агент» и введите `ISOLATED`. Для каждого нового
   запуска это подтверждение требуется снова.

Приложение вызывает существующий `central_playout.run()` в отдельном
потоке с теми же проверенными `isolated_event_assets`, что и
`start_mchs_test.py`. Приём и завершение событий, защиту от повторов,
файловые SHA256 и отчёты `MCHS_EVENT_OBSERVATION_ACCEPTED` обрабатывает
тот же модуль Agent. При закрытии приложения поток корректно останавливается.
Эфирный тракт Worker, веб-радио и громкоговорители не получают учебную команду.

## Важные границы

- **Режим не включается автоматически при входе в Windows.** Автозапуск
  открывает окно, а выбор изолированного МЧС по умолчанию снят.
- Запуск блокируется, если в GUI разрешено управление усилителем через ESP32.
  Пока действует изолированный режим, повторное включение реле в GUI
  блокируется, а ESP32-ключи не передаются аудиопроцессу.
- Даже корректный отчёт о завершении WAV не доказывает физическую слышимость.
- Это не активация настоящего оповещения через PA; `HALT` и ограничения
  реального START остаются в силе.
- Для старого Python-пилота возможен прежний запуск, но дальнейшие тесты
  рекомендуется проводить через один EXE, а не две копии Agent одновременно.
