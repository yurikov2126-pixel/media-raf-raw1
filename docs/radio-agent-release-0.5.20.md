# Windows Radio Agent v0.5.20 — релиз 7 ноября 2026

## Состав выпуска

- События основного Radio Worker `MISSILE_DANGER` и `MISSILE_ALL_CLEAR` учитываются как запрос на питание ESP32 в AUTO. Связка с API из PR #1025.
- Windows Agent принимает подписанное сервером разрешение `policyMode:MCHS` независимо от состояния обычного музыкального воспроизведения, не обходя операторский аппаратный допуск, ручной OFF, emergency OFF, привязку к одному ESP32 и защитную аренду питания.
- PR #1030: в диагностике `INTENT_RESPONSE`, `POWER_COMMAND`, `RELAY_TRANSITION` сохраняется идентификатор **действительного** оповещения; помечается стадия `MCHS_PRE_ROLL`, если Worker сообщает о ней. Это необходимо для расследования не включившегося AA-300.
- Серверный pre-roll МЧС остаётся **отключён по умолчанию** (`RADIO_MCHS_POWER_PREROLL_MS=0`). Увеличивать задержку настоящей тревоги без отдельной безопасной аппаратной приёмки нельзя.
- Обычное вещание, AUTO/MANUAL, экстренная защита, сохранённые секреты и существующий процесс автообновления сохраняются.

## Публикация

Версия в `radio-agent/windows/gui.py`: **0.5.20**. Проверяемый официальный тег: `radio-agent-v0.5.20`. Workflow `Windows Radio Agent EXE` при объединении в `main` создаёт GitHub Release и загружает `MediaRafRaw-RadioAgent.exe`, проверяя SHA-256 по GitHub API. Публикацию нельзя считать успешной только по наличию CI-артефакта: нужна строка `RELEASE_PUBLISHED_AND_VERIFIED` и соответствующий EXE в GitHub Release.

## Установка

Во время действующего ALARM/ALL-CLEAR **не перезапускать** Windows Agent. После завершения эфира скачать EXE из официального выпуска, остановить старый Agent, установить новую версию, проверить `0.5.20` в GUI, авторизацию, IP ESP32, включённый аппаратный допуск и сохранность токенов. Установщик не должен переписывать секреты.

**Важно:** программные изменения не доказывают физическое включение AA-300 и доступность коридорных громкоговорителей. Система МЧС ещё требует очной проверки силового тракта и подтверждения звука; штатные средства экстренного оповещения остаются основными.
