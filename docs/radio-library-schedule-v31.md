# Radio Workspace 3.1 — Audio Library + Broadcast Schedule

## Принципы, взятые из эфирных систем

Rivendell RDLogEdit показывает эфирные события в хронологическом журнале, а RDLogManager позволяет организовать сетку по дням недели и часовым шаблонам. Мы применяем эти проверенные подходы к имеющемуся календарю, не меняя механизм расписания.

Источники:
- https://opsguide.rivendellaudio.org/html/chapter.rdlogedit.html
- https://opsguide.rivendellaudio.org/html/chapter.rdlogmanager.html

## Аудиотека

- Новая модель `RadioAssetFolder`: папки и вложенные папки, без перемещения физических файлов на диске.
- `RadioAsset.folderId` и `RadioAsset.tags`: сохранённые структуры каталога и ID3-метаданные.
- Загрузка получает теги из ffprobe (MP3 ID3v2 и метаданные других контейнеров). Обновление тегов редактирует **метаданные платформы**, не встраиваемые теги оригинального MP3.
- UI: дерево папок, хлебные крошки, поиск в выбранной папке по метаданным, сортировка, плитка/список, предпрослушивание, редактор тегов, перемещение в папку, безопасное удаление.
- Запрет удаления непустой папки, запрет удаления файлов, используемых плейлистами, сохраняется.
- Auto-DJ продолжает выбирать треки по существующим ID; `storageKey` и файлы остаются без изменений.
- При хранении >300 файлов учесть: старый API `GET /assets` возвращает максимум 300 записей; нужна последующая серверная пагинация и виртуализация интерфейса. Текущий PR оставляет это ограничение неизменным.

## Сетка вещания

- Недельная сетка из 7 колонок, дата станции Europe/Moscow, переключение неделя / хронология.
- Навигация на прошлую и следующую неделю, переход к текущей дате.
- Отображение названий плейлистов и времени передач, маркеры пересечения интервалов.
- Клик по событию использует существующее контекстное меню управления эфиром. Создание новых передач открывает существующий валидируемый редактор; сервер остаётся источником истины.
- Пустое место не означает автоматически подтверждённый Auto-DJ — только визуальный placeholder.

## Прежде чем объединять

1. Prisma migration на копии базы и Prisma generate.
2. Server Vitest + client build/lint.
3. Импорт MP3 с русскими ID3, FLAC/WAV/M4A; проверка тегов и ресканирования.
4. Перемещение записи в папку и обратно; плейлист после перемещения продолжает проигрываться.
5. Проверка пересечений, создания, редактирования/переноса, московского UTC+3, мобильной сетки.
6. Миграция существующих файлов: все старые записи остаются в корне и без дополнительных ID3 до ресканирования.

Ни одна новая операция не управляет MP3 Worker, радиоусилителем, Windows Agent или ESP32.
