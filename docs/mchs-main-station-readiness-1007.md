# PR #1007 — готовность основного МЧС-тракта (только чтение)

Добавлен защищённый ролью ADMIN маршрут `GET /api/safety/missile-main-station-readiness` (префикс `/api/safety` зависит от регистрации Express). Он не отправляет PCM, команд START/STOP или команд ESP32.

Данные:
- Авторизованный internal `GET /mchs-station-session` через `requestMchsStationSession({action:'STATUS'})` — доступность Radio Worker, активная фаза, `terminalJournal.healthy`, состояние трех конфигурационных флагов.
- PostgreSQL `mchs_station_execution_receipts_v1` — количество подтверждённых `COMPLETE` с признаками подмены PCM и возобновления обычной программы. Это подтверждение **только** в точке общего энкодера, не физическая слышимость.
- Текущее `radioDevice.lastSeenAt` зарегистрированного Windows Agent и `playbackAllowed` — присутствие, но не звук на выходе.
- Последняя привязанная к Agent запись `radio_esp32_status_v1` с TTL 12 секунд — heartbeat, lease, relayOutputEnabled, commanded power. Это **не** доказательство стабильности 220 В и не независимое подтверждение включения усилителя.

В ответе всегда `readyForLivePA:false` и `status:'HOLD'`, пока нет отдельной независимой телеметрии звукового выхода и отсутствия dropouts. Заполнение всех полей heartbeat и даже включение трех флагов не превращает отчёт в разрешение трансляции.

**Ограничения:** привязка Windows Agent сейчас берётся из `MCHS_AGENT_LAB_DEVICE_ID` — действующего административно настроенного идентификатора. Неизвестное устройство не считается готовым. Для реального переключения следует перейти к отдельной постоянной production-привязке без старых lab-флагов, сквозному наблюдению PCM от Worker к Agent и измерению изменения GPIO13, lease, 3-секундного прогрева, стабильности усилителя и возможности вернуть обычную музыку. В данном PR этих управляющих действий нет.

## Безопасность
- Никакой автоматической активации ALARM, никаких смен режимов реле.
- Не изменяются `MCHS_ANDROID_MAIN_STATION_DISPATCH_ENABLED`, `MCHS_MAIN_STATION_COORDINATOR_ENABLED`, `RADIO_MCHS_STATION_COMMANDS_ENABLED`.
- Результат предназначен для диагностики и не может быть использован как управляющее разрешение. При пропавшей связи, устаревшем heartbeat или повреждённом Worker journal отчёт сохраняет HOLD.
