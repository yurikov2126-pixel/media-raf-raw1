# Радио 2.0 — Windows: пилотный локальный эфир

## Возможности и ограничения
Пробный эфир **по умолчанию запрещён** и включается только сочетанием:
1. Переключателя конкретного устройства у ADMIN в «Радио → Оборудование».
2. Запуска локального скрипта `pilot_playout.py` с флагом `--enable-local-speaker`.

VLC воспроизводит только из локального проверенного SHA-256 кэша на стандартный аудиовыход Windows. Скрипт запускает программу только в первые 10 секунд после планового начала, отмечает ID слота как использованный **до старта**, чтобы не повторять эфир при перезапуске. При отсутствии файлов или связи он пропускает эфир. Он не управляет ESP32, реле, усилителем или системой обязательного оповещения.

Важно: отключение разрешения на сайте проверяется между дорожками. **Уже запущенную дорожку оно мгновенно не остановит**. Для немедленного прекращения аудио остановите VLC/скрипт на ноутбуке. Полный offline/failover, строгая синхронизация, журнал подтверждённого звучания и мгновенный удалённый STOP ещё не реализованы; на рабочую акустическую систему колледжа пока не подключать.

## Ubuntu 24.04 + aaPanel
Новых системных пакетов и npm-зависимостей нет. Нужна новая миграция Prisma `20261017110000_radio_device_playback`: добавляет `RadioDevice.playbackAllowed` с `false` по умолчанию.

Порядок: backup БД → merge после CI → штатный production deploy (включая prisma migrate deploy и prisma generate) → проверить ADMIN «Радио → Оборудование». Дополнительные nginx/aaPanel-настройки не требуются.

## Windows 10 / Windows 11
Нужны Python 3.11+ (см. этап синхронизации) и **VLC media player** с официального сайта VideoLAN: https://www.videolan.org/vlc/ (установка через обычный Windows installer). Для пилота НЕ нужны дополнительные pip-пакеты.

1. Подключите к ноутбуку **только локальные наушники/тестовые колонки**. Не подключайте AA-300 или общую сеть оповещения.
2. Убедитесь, что `sync_agent.py` и `pilot_playout.py` находятся в одной папке `C:\RadioAgent\`.
3. Под ADMIN зарегистрируйте устройство или используйте сохранённый токен. Включите «Разрешить тестовый эфир».
4. Откройте PowerShell **в интерактивной пользовательской сессии**; убедитесь, что VLC установлен по пути `C:\Program Files\VideoLAN\VLC\vlc.exe` (путь может отличаться).
5. Для одного ручного тестового запуска синхронизации:

```powershell
$env:RADIO_AGENT_TOKEN = Read-Host "Введите токен радиокомпьютера"
python C:\RadioAgent\sync_agent.py --server https://mediarafraw.ru --data-dir C:\RadioAgent\data --once
```

6. Когда расписание настроено на ближайшие минуты, запустите пилот:

```powershell
python C:\RadioAgent\pilot_playout.py --server https://mediarafraw.ru --data-dir C:\RadioAgent\data --vlc "C:\Program Files\VideoLAN\VLC\vlc.exe" --enable-local-speaker
```

7. Для остановки нажмите `Ctrl+C` и проверьте, что дочерний VLC завершён. Затем выключите разрешение в веб-интерфейсе и удалите токен из окружения PowerShell:

```powershell
Remove-Item Env:\RADIO_AGENT_TOKEN
```

**Не настраивайте автозапуск в Планировщике заданий Windows на этом этапе.** На Windows 10 после 14 октября 2025 года обычная поддержка закончилась; рассмотрите Windows 11 или официальную программу ESU прежде чем постоянно подключать устройство к сети.

## Проверки перед слиянием
- При выключенном разрешении статус остаётся SYNC_ONLY, воспроизведение не запускается.
- Ручной запуск без флага `--enable-local-speaker` отклоняется.
- Подтверждённый администратором PILOT-запуск воспроизводит тестовую передачу в наушники и не повторяет слот после перезагрузки.
- Повреждённый файл не воспроизводится, а отозванный токен прекращает следующий цикл синхронизации.
- UTC-расписание запускается в правильный московский час, системные часы Windows синхронизированы (ошибка больше 30 секунд блокирует запуск).
- STUDENT не может включить/выключить разрешение; сервер не имеет команд к ESP32/усилителю.
- После отключения разрешения у ADMIN следующий трек не запускается.
- Выполнить серверные/клиентские тесты и пилот на тестовых колонках перед слиянием.
