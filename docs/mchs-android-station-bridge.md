# МЧС: Android → центральный координатор → основной Radio Worker

Этап после PR #1000. Монитор `tickMchsAndroidMonitor` обнаруживает новые записи `MCHS_ANDROID`, связывает их с категорией `ALARM` и сохраняет долговременный ledger до отправки. Только *новые* привязки передаются в `dispatchNewAndroidStationBindings`; история не переигрывается при перезапуске Express.

Для `MISSILE_DANGER` используется назначенный ALARM и число повторов из настроек. `MISSILE_ALL_CLEAR` всегда однократный. Worker сам завершает PCM и возвращает обычную программу. Команда STOP при штатном окончании не отправляется. Ошибка транспорта считается ошибкой, а не подтверждением PCM или слышимости.

## Deployment gates (все по умолчанию выключены)
- `MCHS_ANDROID_MAIN_STATION_DISPATCH_ENABLED=true` — разрешение отправки из API-монитора;
- `MCHS_MAIN_STATION_COORDINATOR_ENABLED=true` — разрешение локального API→Worker транспорта;
- `RADIO_MCHS_STATION_COMMANDS_ENABLED=true` — разрешение основного Worker START.

Внимание: включение всех трёх флагов разрешает **настоящую замену PCM в основном потоке**. Общий поток может поступать Windows Agent и в аппаратный PA. Этот PR **не** включает флаги, не управляет ESP32 и не подтверждает безопасность физического усилителя. До разрешения реальной передачи необходимо отдельно проверить настройку маршрутов, физическую изоляцию или безопасное управление громкоговорителями и отсутствие падений питания усилителя.

Источником событий остаётся существующий авторизованный Android intake. Для каждого нового события перепроверяются источник, тип, регион, свежесть, связанный файл и повторы. Локальная проверка является защитой от неверных/устаревших команд, а не новым ручным подтверждением уведомления.

`MCHS_ANDROID_STATION_DISPATCH` журналирует принятые и отклонённые команды. HTTP START и статус Worker не являются гарантией слышимости в браузере. У нового моста пока нет durable receipts переходов PLAYING/COMPLETE или обработки последовательности опасность→отбой при наложении. Эти функции и согласование Agent/ESP32 являются следующими работами; включать реальные три флага пока рано.
