# Экстренное оповещение — этап 1

Это подготовительный этап административной панели и пульта ответственного за безопасность, а НЕ действующая система оповещения.

- Админка: вкладка «Экстренное оповещение»; сохранение региона, будущих направлений доставки и примечаний.
- Пульт: `/app/safety`, доступ на сервере через `safety.view` из RBAC. Администратору доступен всегда.
- API: `GET /api/safety/dashboard` и `GET /api/safety/access` требуют `safety.view`; `PUT /api/safety/config` только ADMIN.
- Даже поддельный HTTP-запрос не может установить `enabled=true` или `testMode=false`. Никаких API для запуска сирен, радио или громкоговорителей нет.
- Конфигурация и последние 100 изменений сохраняются в таблицу Setting; журнал событий намеренно пуст до создания защищённого приёмника.
- `mchs-android` пока недоступна для тестирования; данные с неё не подтягиваются.

До следующего этапа необходимо создать аутентифицированный канал приёма, защиту от повторов, хранилище событий, привязку к территории, тесты после потери сети и перезагрузки, строгую авторизацию команд и независимую процедуру аварийного отключения. Реальный автоматический запуск заблокирован.
