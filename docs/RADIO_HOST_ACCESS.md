# Радио: должность «Радиоведущий» и включаемый пункт меню

## Должность
Код `RADIO_HOST`, название «Радиоведущий» добавляется к системным должностям и в уже сохранённые справочники. Её можно назначить студенту в **Админка → Команда редакции → Редактор должностей / Состав редакции**. Код и наименование этой системной должности защищены от удаления и переименования, потому что на ней основано ограничение доступа.

## Доступ
- ADMIN: полный интерфейс `/app/radio` и существующие администраторские радио API.
- STUDENT с должностью `RADIO_HOST` в `EditorialTeamMember.position`: интерфейс `/app/radio/playlists/my` и API `/api/radio/student/*`.
- Остальные студенты, преподаватели и другие роли: нет доступа к студенческому радио API.
- Маршрут и навигация проверяют `GET /api/radio/access`; недостаточно подставить URL или добавить пункт вручную.
- После изменения должности потребуется повторное открытие раздела или обновление страницы, чтобы заново получить доступ.

## Меню
В **Админка → Дизайн сайта → Меню** каталог пунктов дополнен Радио с собственной линейной иконкой микшерного пульта `radioStudio`. Добавляйте этот пункт мышью отдельно в ПК, мобильном браузере и PWA (нижнее меню или «Ещё»), затем **Сохранить всё**.
Само наличие должности даёт право доступа, а видимость пункта регулируется настройками меню. Раздел не включается автоматически для всех.

## Ручная проверка
1. Назначить одному студенту `RADIO_HOST`; у второго оставить прежнюю должность.
2. Включить Радио в меню сайта для ПК, мобильного браузера и PWA.
3. У администратора открыть `/app/radio`; у радиоведущего — `/app/radio/playlists/my`.
4. У обычного студента радио-пункт должен отсутствовать; прямой GET /api/radio/student/playlists должен вернуть 403.
5. Снять должность у радиоведущего и убедиться, что повторный запрос к API немедленно даёт 403.
6. Проверить иконку и светлую/тёмную темы, iPhone/PWA и мобильную навигацию.
