# MEDIA · РАФ · RAW — физическое управление усилителем ESP32

## Требования к проверенной аппаратной части

GPIO 13, активный уровень HIGH: HIGH включает релейный вход, LOW выключает. При запуске и истечении разрешения прошивка принудительно выставляет LOW. **Физический pull-down и силовой коммутационный узел должны обеспечивать OFF ещё до старта прошивки**; GPIO может находиться в неопределённом состоянии при загрузке. Не используйте номинал 10 А на SONGLE как достаточное доказательство пригодности для сетевого усилителя с пусковым током. Проверка электриком, защитный автомат, изоляция и ручное обесточивание обязательны. Первоначальный запуск рекомендован без сетевой нагрузки, затем — после проверки — в контролируемой студийной среде.

## Развёртывание

1. Объединить PR, дождаться успешных тестов сервера, клиента, Windows EXE и сборки ESP32 PlatformIO.
2. Заменить опубликованный ранее секрет на новый случайный секрет 32+ символа, только локально в `radio-agent/esp32/include/secrets.h`, не публиковать его.
3. Прошить ESP32 из `radio-agent/esp32` через PlatformIO. Версия `/health`: `POWER_CONTROL_V1`, `relayActiveLevel: HIGH`, `amplifierPower: OFF_COMMANDED`, `bootNonce` и курсоры anti-replay.
4. На Windows установить Windows Radio Agent **0.3.5** из нового релиза, открыть настройки; добавить `10.0.1.58`, токен зарегистрированного Windows Radio Agent и секрет сопряжения.
5. В «Радио → Эфирный пульт» выбрать AUTO или MANUAL, проверить `amplifierPower`, онлайн-статус и `emergencyOff`.
6. В Windows Agent в «Настройки» включить явное разрешение управлять физическим реле, только после аппаратной проверки.
7. В AUTO сервер разрешает запрос за 60 секунд до APPROVED расписания или при включённом Auto-DJ. В MANUAL администратор задаёт запрос вручную. Аварийный стоп на сервере всегда имеет приоритет, когда агент онлайн.

## Защиты

- Сайт не имеет сетевого доступа к ESP32; Windows Agent через HTTPS запрашивает `/api/radio-agent/agent/amplifier-intent` со своим действующим `rr_` токеном.
- Только Agent со включённым `playbackAllowed` получает `permit=true`.
- Каждые ~3 секунды Windows Agent передаёт команду на ESP32 по LAN, подписанную HMAC-SHA256 от bootNonce, sequence и разрешения. Физический выход активируется на максимум 8 секунд без обновления.
- Протокол heartbeat также подписан HMAC; секрет в новых запросах не передаётся, а повторные команды отвергаются.
- Отсутствие heartbeat (10 сек), истечение разрешения (8 сек), потеря Wi-Fi или перезапуск ESP32 приводят к LOW/OFF.
- При сбое интернета продлевается **только предварительно разрешённое** питание при реально работающем Windows LOCAL_RESERVE, не дольше 15 минут с момента последнего подтверждённого сервера. При сетевой изоляции платформа не может немедленно доставить аварийный стоп, поэтому требуется доступный физический выключатель.
- `ON_COMMANDED` подтверждает команду выхода GPIO, **не доказывает наличие напряжения на контактах усилителя** — датчик обратной связи не установлен.
- GUI показывает ошибку команд отдельно от состояния соединения.

## Ограничения

После отключения работы Windows Agent или закрытия GUI, ESP32 выключит реле по watchdog. Приложение автоматически открывается при входе Windows, если включён автозапуск; токены можно сохранять в шифрованном хранилище DPAPI. Автоматический запуск эфира пока остаётся отдельной задачей.
