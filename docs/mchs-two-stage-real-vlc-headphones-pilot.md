# МЧС #970 — учебный цикл «ALARM → музыка → отбой → музыка»

Это **реальный локальный звук в отдельных процессах VLC** на Windows,
но **не** автоматическое реагирование на Android/МЧС и **не** общий
поток Worker. Обязательно физически отключить AA-300 и любые альтернативные
линии PA. ESP32 не использовать. Испытание доступно только оператору,
который вручную запускает скрипт и подтверждает `ISOLATED`.

## Последовательность

1. Открыть музыкальный файл в отдельном локальном VLC-процессе.
2. Остановить **только этот процесс**, запустить локальный WAV «опасность»
   1–5 раз и дождаться подтверждённого естественного окончания всех повторов.
3. Снова открыть музыку и дать ей прозвучать несколько секунд.
4. Остановить свой музыкальный процесс, проиграть WAV «отбой» **один** раз,
   дождаться естественного завершения.
5. Снова открыть музыку и проверить наличие процесса. После короткого
   прослушивания завершить все процессы, принадлежащие пилоту.

Два WAV должны быть разными файлами с различным содержимым, PCM16,
24/48 kHz mono/stereo, продолжительность каждого до 120 секунд.
Каждый файл проверяется перед запуском.

## Запуск из PowerShell

Подготовить два *учебных* файла с понятной маркировкой «Тест».
Они **не** загружаются в общую библиотеку или публичный Worker.

```powershell
cd radio-agent/windows
python .\mchs_two_stage_headphones_pilot.py --vlc "C:\Program Files\VideoLAN\VLC\vlc.exe" --program-file "C:\TestMusic\track.mp3" --danger-wav "C:\MchsTest\danger-test.wav" --all-clear-wav "C:\MchsTest\all-clear-test.wav" --danger-repeats 4
```

Успешный итог: `LOCAL_TWO_STAGE_RESULT` дважды с `ok: True`,
`natural: True`, `programRestored: True`, затем
`ISOLATED_TWO_STAGE_COMPLETE`. В нормальном ходе STOP не посылается
в радио-систему — VLC завершается сам после полного файла. При ошибке
вторая стадия не запускается, а скрипт очищает свои дочерние процессы.

## Чего тест НЕ подтверждает

- Он **не переключает действующий** `central_playout.py` и не проверяет
  доставку команд Android или Worker.
- Новая музыка запускается с начала локального файла, а не с текущей
  позиции общей программы.
- Живой Windows Agent продолжает работать отдельно. Если он тоже
  воспроизводит музыку на этом выходе, звуки **наложатся**. Используйте
  отдельный выход/контролируемую остановку звука других приложений.
- Не подтверждает акустическую готовность PA, не разрешает публичную
  тревогу и не заменяет проверку настоящего event-bound двухканального
  цикла. После этого этапа следует именно интеграция в управляемый
  изолированный режим рабочего Agent.

Тесты:

```powershell
cd radio-agent/windows

```
