# МЧС — учебный звук в действующем Windows Radio Agent

Экспериментальная функция только при физически отсоединённом кабеле звукового выхода радиокомпьютера к усилителю AA-300. Подтвердить отсутствие альтернативного маршрута в PA. Не заменяет систему экстренного оповещения.

1. Запустить учебную PCM-сессию Worker с собственным коротким голосовым сообщением, не имитирующим реальную тревогу.
2. В API включить MCHS_AGENT_LAB_STREAM_ENABLED=true и задать MCHS_AGENT_LAB_DEVICE_ID равным ID действующего тестируемого Agent. Не публиковать токен.
3. Отключить физический кабель к AA-300; для прослушивания можно подключить наушники к тому же выходу на минимальной громкости.
4. Запустить обычный Windows Radio Agent, проверить нормальный эфир.
5. Нажать «Учебный звук МЧС (кабель PA отключён)» и подтвердить физическое отключение.
6. Агент завершает основной и резервный VLC, запускает учебный WAV поток в новом VLC на том же Windows output, максимум 30 секунд.
7. «СТОП МЧС / вернуть радио» или таймаут завершает тест. Agent возобновляет обычное подключение к серверу или резерву по штатной логике.
8. Вернуть кабель к усилителю только после подтверждения завершения тестового VLC и нормального состояния радио.

Ограничения: переход не бесшовный, не гарантирует точную позицию композиции и не является crossfade; автоматический запуск при реальном оповещении отсутствует. Кнопка не управляет реле/ESP32. Программное подтверждение физического отключения невозможно. Отключить лабораторный флаг API после испытаний. Если учебный поток недоступен, VLC может не воспроизвести звук.
