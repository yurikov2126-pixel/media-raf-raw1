# Radio Agent macOS — локальный прямой эфир (пилот)

**Режим не передаёт звук на сервер, в браузер или на другие устройства.** Это прослушивание живого микрофона на выбранном локальном аудиовыходе Mac. Пока не является готовым маршрутом вещания и не управляет AA-300/ESP32.

## Установка на Mac
Нужны установленный Python 3 с Tkinter (как для GUI-пилота) и пакет **sounddevice** для CoreAudio/PortAudio. Устанавливать на Ubuntu 24.04 ничего не нужно, миграций Prisma нет.

В Terminal, в папке с `gui.py` и `live_audio.py`:

```bash
python3 -m pip install sounddevice
python3 -c "import sounddevice as sd; print(sd.query_devices())"
python3 gui.py
```

Если Python управляется Homebrew и запрещает системную установку пакетов, используйте виртуальное окружение:

```bash
cd /ПУТЬ/К/ПАПКЕ/radio-agent/macos
python3 -m venv .venv
source .venv/bin/activate
python -m pip install sounddevice
python gui.py
```

Используйте тот же интерпретатор Python, с которым успешно запускается Tkinter.

В **Системные настройки → Конфиденциальность и безопасность → Микрофон** предоставьте разрешение приложению Terminal/Python, если macOS запросит доступ.

## Проверка
1. Подключите наушники к Mac и выберите их как выход в GUI. **Не выбирайте встроенные динамики рядом с открытым микрофоном:** акустическая обратная связь может вызвать очень громкий свист.
2. В RADIO → Оборудование у этого Mac должен быть включён PILOT. Нажмите «Проверить связь».
3. Выберите микрофон и аудиовыход в разделе «Локальный прямой эфир».
4. Подтвердите запуск. Должен появиться уровень входного сигнала, а ваш голос — в наушниках. Начинайте с минимальной громкости.
5. Нажмите «Выключить микрофон»: локальный сигнал должен прекратиться. Закрытие GUI также прекращает процесс.
6. При активном микрофоне кнопки автоматического пилота и проверки аудиофайлов не должны запускать второй аудиопоток.
7. Уберите разрешение в админке и проверьте запрет следующего запуска. **Админское отключение не завершает уже активную сессию мгновенно** — немедленно остановить её нужно локально.

## Ограничения
- Нет записи эфира, удалённых ведущих, потоковой передачи, микширования и плавных переходов.
- Прямое прослушивание работает только с открытой графической сессией macOS.
- Автоматическая приоритизация запланированных передач пока не реализована. Для реальной студии нужны защита от одновременного аудио, подтверждение отключения вывода, выравнивание уровней и управление приоритетами.
- Системный аудиодвижок определяет задержку, возможна небольшая задержка мониторинга.
- Это пилот на локальных наушниках, не рабочий эфир колледжа.
