# Политех-FM — приёмка Smart Crossfade 2.0

## Перед тестированием
- Убедиться, что основной Worker использует непрерывный MP3 encoder; сохранить конфигурацию systemd и значения переменных окружения.
- Миграция плейлистов должна быть применена до запуска Worker.
- `RADIO_SCHEDULED_CROSSFADE_ENABLED` должен иметь одинаковое значение на API и Worker. При выключенном флаге существующее расписание работает без нового наложения.
- Старые запланированные интервалы `endAt` **не пересчитываются автоматически**. Перед экспериментом назначить новую программу с актуальной длительностью наложений, убедиться в отсутствии конфликтов.
- До включения проверить, что оба файла каждого перехода доступны Worker и имеют валидные cue/длительности.

## Минимальный сценарий принятия
1. AutoDJ → AutoDJ, включая завершение джингла.
2. Эфирная программа: последовательность как минимум из пяти треков с разными перекрытиями.
3. AutoDJ → эфирная программа точно по началу слота, затем возврат к AutoDJ.
4. Тот же переход с опцией «Доиграть трек до конца».
5. Удалённый/нечитаемый второй файл: убедиться, что Worker зафиксировал ошибку, поток продолжил работу.
6. Повторный запуск Worker на середине наложения; проверить, что второй трек не начинается дважды.
7. Прослушать один и тот же участок с сайта и Windows Agent; записать WAV PCM или MP3 для offline проверки.

## Критерии
- Кодировщик не перезапускается при штатном переключении источников.
- `crossfadeAttempted`, `crossfadeCompleted`, `crossfadeFailed`, `crossfadeFallbacks` объяснимы по событиям.
- `crossfadeQuality.suspiciousJumps` — **индикатор**, а не доказательство дефекта: музыкальные транзиенты могут быть очень резкими.
- Проверять паузы не по одним нулевым PCM сэмплам: тихая музыка и исходные паузы допустимы.
- Слушать и проверять реальный записанный выход декодера; CI с синтетическими сигналами не доказывает, что в эфире нет артефактов.
- Ни один кусок AutoDJ после программы не должен играть повторно перед новым треком.

## Отключение
1. Снять флаг `RADIO_SCHEDULED_CROSSFADE_ENABLED` у API и Worker согласованно; **не** менять один сервис независимо от другого.
2. Пересчитать/восстановить продолжительность ещё не начавшихся программ в соответствии с классическим режимом до следующего теста.
3. Проверить health Worker, метаданные эфира и вывод сайта/агента.
4. При критическом сбое использовать имеющийся штатный механизм восстановления Worker; нельзя обещать безразрывный откат при перезапуске encoder.

## Известные ограничения
- Переходы AutoDJ ↔ расписание пока являются **сменой PCM-источника с защитными fades**, а не настоящим двухдековым source crossfade.
- Резерв второго декодера и fallback при ошибке требуют отдельной сквозной проверки.
- Телеметрия собирает данные только на сервере, а не измеряет фактическое звучание устройств слушателей.
