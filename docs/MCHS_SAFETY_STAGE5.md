# МЧС: этап 5 — тестовый отправитель с локальной очередью

Из исходников уже собранного ранее Android Bridge известно, что `MchsNotificationListener` пишет JSON `event=posted` в Android `logcat` с тегом `MCHS_BRIDGE`, полями package/key/postTime/channel/title/text/bigText. Новый Python-агент понимает **только** события `posted` из `io.citizens.security`; любые другие отбрасываются.

## Что реализовано
- Python 3 без внешних зависимостей: сбор сообщений с ADB `127.0.0.1:5557`, точный JSON, SQLite/WAL в `/var/lib/mchs-sender`, идемпотентный ID SHA256; ни одного вызова к звуковому оборудованию.
- Подтверждение доставки — только HTTP 200 плюс `accepted=true`. При ошибках сохраняется очередь и экспоненциальный backoff.
- Сетевые запросы отключены по умолчанию (`MCHS_SEND_ENABLED=false`). При включении обязательны URL HTTPS и ключ HMAC >=32 символов. Доставляет `POST /api/safety-ingest/event` по протоколу этапа 3.
- Журналы stdout содержат только укороченный hash ID, без содержимого тревог.
- Прототип не гарантирует полноту захвата: `logcat` не является надёжным журналом. Потеря соединения с ADB или перезагрузка Android может привести к пропуску уведомлений. Для круглосуточной службы необходимо перенести надёжную очередь в сам Android Bridge.

## Развёртывание — только после доступа к отдельной VM
1. Проверить версии Android Bridge, подключение ADB, свободное место и статус systemd сервисов.
2. Скопировать `tools/mchs-sender/mchs_sender.py` в `/opt/mchs-sender/`, создать `/var/lib/mchs-sender` с правами пользователя `mchs-android`. Запускать без root.
3. Установить пример `mchs-sender.service` в `/etc/systemd/system/`, оставить `MCHS_SEND_ENABLED=false`; проверить startup, завершение и рестарт.
4. До подключения отправки выполнить `python3 -m unittest discover -s tools/mchs-sender -p 'test_*.py'` и пробный тест на НЕэкстренном уведомлении стороннего приложения (оно игнорируется).
5. Только на preview, отдельно включить `MCHS_INGEST_ENABLED=true` и секретный ключ. Настроить на VM такой же секрет через закрытый файл systemd EnvironmentFile (доступ 0600), HTTPS URL preview и `MCHS_SEND_ENABLED=true`. Пример unit не содержит секретов.
6. Проверить: отправка записывается один раз; отказ сайта оставляет в очереди; после восстановления связи происходит подтверждённая доставка; нет влияния на радио.
7. Prod оставить отключённым, пока не будет проверен полноценный Android sender, доставка FCM и система безопасной ручной проверки.

**Никаких настоящих сообщений МЧС специально не создавать и не подделывать.** Содержимое — только наблюдения, `verified=false`.

## Ограничения
- Отправитель пока не устанавливался на VM.
- Отправитель не делает heartbeat и не подтверждает регистрацию FCM.
- Уведомления, которые уже успели прийти до установки сборщика, не обязательно сохранились в `logcat`.
- Настоящую тревогу из одного push автоматически инициировать нельзя.
