# Radio 2.0 · Политика пустой очереди Auto-DJ

Этот этап продолжает PR #412 (в его ветку уже объединены изменения #413 и #414). Новый PR должен быть объединён **после** #412 в main; до этого он направлен в ветку PR #412.

При включённом режиме строгой паузы повторов в админке появляется **отдельная, по умолчанию отключённая** опция «Не допускать тишину при пустой очереди». Когда все треки ещё находятся в cooldown, Worker выбирает тот, который воспроизводился раньше остальных, и отмечает `queueStatus=FALLBACK_REPEAT` и `cooldownException=true` в health.

**При выборе этой опции строгий запрет повторов не гарантируется.** Без неё сохраняется прежнее строгое поведение с ожиданием. Это компромисс непрерывного эфира и запрета повторов; из пустой музыкальной библиотеки звук создать невозможно. Текущий трек не обрывается ради переназначения. Запланированные передачи сохраняют приоритет.

Crossfade для событийной очереди остаётся выключенным: понадобится отдельная синхронизация перекрытий и журналирования обеих дорожек. Windows Agent, PA, ESP32 и усилитель не меняются.
