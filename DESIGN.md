# DESIGN

Дизайн-система проекта.

## Палитра

Задаётся через `brand_accent_1/2/3` в настройках. По умолчанию:

| Переменная | Значение | Использование |
|------------|----------|---------------|
| `--brand-accent-1` | `#7C3AED` | Фиолетовый (основной) |
| `--brand-accent-2` | `#EC4899` | Розовый (акцент) |
| `--brand-accent-3` | `#06B6D4` | Cyan (вторичный) |

Цвета:
- **Фон:** `#0E0E16` (ink-900), `#171728` (ink-800), `#1F1F30` (ink-700).
- **Текст:** `#FFFFFF`, `rgba(255,255,255,0.7)`, `rgba(255,255,255,0.4)`.
- **Success:** `#84CC16` (lime).
- **Warning:** `#F59E0B` (amber).
- **Error:** `#EC4899` / `#EF4444`.

Светлая тема: `[data-theme="light"]` в CSS.

## Шрифты

- **Основной:** системный стек (SF Pro, Segoe UI, Roboto).
- **Моно (для редактора):** Menlo, Monaco, Courier New.

## Компоненты

### Card

```jsx
<div className="card p-5">…</div>
```

- Фон: `ink-800/60`.
- Граница: `white/5`.
- Радиус: `1rem` (rounded-2xl).
- Тень: мягкая.

### Кнопки

- **`.btn-primary`** — основной CTA. Градиент `var(--brand-gradient)`.
- **`.btn-ghost`** — второстепенная. Прозрачный фон, hover `white/5`.
- **`.chip`** — маленькая плашка. Используется для тегов, статусов.

### Input

```jsx
<input className="input" />
```

- Фон: `ink-700/50`.
- Граница: `white/10`.
- Радиус: `0.75rem`.

### MarkdownView

```jsx
<MarkdownView text={content} className="text-white/85" />
```

Рендерит markdown с классами `.mrr-md-content`:

- `h1`–`h6` — заголовки с разными размерами.
- `p` — параграфы.
- `ul`/`ol` — списки (маркеры фиолетовые).
- `blockquote` — цитата с фиолетовой полосой.
- `code` — inline-код.
- `pre > code` — блок кода.
- `a` — ссылки.
- `hr` — разделитель.
- `table` — таблицы.

### Модалки

Портал в `document.body` + `pushModal()` для блокировки свайпов между чатами.

```jsx
{open && createPortal(<div className="fixed inset-0 z-[200] …">…</div>, document.body)}
```

z-index:
- **200** — обычные модалки (ImageViewer, Cropper).
- **100** — NotificationBell panel.
- **80** — контекстные меню.
- **50** — CourseEditor.
- **40** — чат-комната.

### Иконки

- Основные — emoji (универсально).
- Логотип — SVG (если есть).

### Анимации

- `animate-pop` — модалки и меню.
- `page-enter` — переходы между страницами.
- `transition-all` — на кнопках.

## Тёмная и светлая тема

Класс `[data-theme="light"]` в CSS.

Правило: если компонент использует `bg-white/5`, то в светлой теме — `bg-black/5`.

Для контента `.mrr-md-content` — отдельные стили под светлую тему.

## Адаптивность

- **Mobile-first.**
- Брейкпоинты Tailwind: `sm` (640), `md` (768), `lg` (1024).
- Сайдбар на мобиле — `MobileNav` снизу.
- На десктопе — сайдбар слева 64.

## Тонкости

### MarkdownView

Не поддерживает:

- Вложенные списки (только один уровень).
- HTML внутри markdown.
- LaTeX.

### Emoji

Везде используются emoji вместо иконочных шрифтов — это проще и работает везде.

### Тени

Очень мягкие. `shadow-2xl` только для модалок.

### Скругления

- `rounded-xl` (0.75rem) — маленькие.
- `rounded-2xl` (1rem) — основные.
- `rounded-3xl` (1.5rem) — крупные.

## Плейсхолдеры

- Аватары — первая буква имени в круге с градиентом.
- Обложки — `linear-gradient(135deg, #7C3AED 0%, #EC4899 100%)`.
- Курсы — иконка категории в углу.

## Статусы

- **PENDING** — amber.
- **APPROVED** — emerald.
- **REJECTED** — red.
- **PUBLISHED** — lime.
- **DRAFT** — white/10.
